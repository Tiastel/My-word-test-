# 내가 연습하려고 만든 단어장

수능, 편입, 고등, 토익 수준의 영단어를 암기 가능

단어를 직접 추가 및 변경하는 기능을 추가해서 진정한 나만의 단어장 생성 가능

## 업데이트 내역
- **06-27**: 오답노트 랜덤 및 범위 지정 실행 기능 추가
- **06-29**: 스마트 셔플 기능 추가 (단어 랜덤 방식 개선), 단어장에서 단어 직접 수정 기능 추가
- **06-30**: 롤백. 페이지 메뉴에서 단어 선택 기능 제거
- **07-05**: 15,000단어 정비 완료 및 최신화
- **10-14**: 네이버 표준 어학사전 기준 단어 뜻 대대적 정제
  - 유의어/동의어 중복 단일화 (예: `garrulous` -> `수다스러운`, `장황한`)
  - 조사 및 문법 차이 통일 (예: `~하려고 노력하다`)
  - 구형 덤프 고어/비표준 뜻 완전 퇴출 (`eat`: `먹다`, `drink`: `마시다`, `walk`: `걷다`, `run`: `달리다`, `sleep`: `자다`)
  - 명사/동사 품사 다의어 온전 유지 (`ban`: `금지하다`, `금지` 등)
  - 단어당 최대 4개 이하 최빈출 핵심 의미로 압축 정돈
